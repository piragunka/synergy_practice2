# WORKER

Учебная программа для работы с информацией о работниках организации.

Программа разработана в рамках производственной практики.

## Назначение

Программа позволяет вводить данные работников и выводить фамилии сотрудников,
стаж работы которых превышает указанное пользователем значение.

## Структура проекта

```text
worker-practice/
│
├── worker.py
├── main.py
├── test_worker.py
└── README.md
```

## worker.py

Содержит класс `WORKER`.

Класс хранит:

- фамилию и инициалы работника;
- должность;
- заработную плату;
- год поступления на работу.

В классе реализованы:

- конструктор по умолчанию;
- конструкторы с параметрами;
- деструктор;
- изменение данных;
- отображение данных;
- вычисление стажа.

## main.py

Основной файл программы.

Он выполняет:

1. Ввод количества работников.
2. Ввод данных каждого работника.
3. Создание объектов класса `WORKER`.
4. Сохранение объектов в стандартном списке Python.
5. Ввод требуемого стажа.
6. Поиск работников с большим стажем.
7. Вывод их фамилий.
8. Вывод сообщения при отсутствии подходящих работников.

## test_worker.py

Содержит автоматические тесты класса `WORKER`.

Проверяются:

- конструктор по умолчанию;
- создание объекта с параметрами;
- дополнительные конструкторы;
- изменение данных;
- вычисление стажа.

## Запуск программы

```bash
python main.py
```

## Запуск тестов

```bash
python -m unittest test_worker.py
```

## Ограничения текущей версии

Текущая версия является первоначальным вариантом программы.

На данном этапе отсутствуют:

- проверка корректности заработной платы;
- проверка года поступления;
- проверка пустых текстовых полей;
- обработка ошибок пользовательского ввода;
- защита атрибутов от прямого изменения;
- постоянное хранение введённых данных.

Эти ограничения могут быть устранены при дальнейшем развитии программы.
